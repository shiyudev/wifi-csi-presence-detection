# CSI 占据检测 · 二分类实验台（浏览器端 UI）

纯前端页面，双击 `index.html` 即可打开（无需服务器）。四个页签：

| 页签 | 功能 |
|---|---|
| 实时检测 | 接入 CSI 数据源，浏览器端实时推理并显示 有人/无人 判定与分数曲线 |
| 模型评估 | 用真实测试窗口重算指标：准确率 / 混淆矩阵 / 阈值灵敏度（拖动阈值即时重算） |
| 数据与标签 | 录制总表、标签口径、实验局限；逐文件真值 / 用途 / 帧数 / 可用窗口 / 测试准确率 |
| 实验设置 | 判定参数在线调节；数据集与推理接入契约（`pushPrediction` / `pushFrame` / `POST /predict`），换模型换数据集无需重写界面 |

数据源支持演示流 / 回放 / 实时三种模式（`assets/data.js` 内置演示数据，
`assets/model.js` 内置浏览器端模型）。与 [Model_v9/](../Model_v9/) 的
`predict.py` 输出契约一致。

> 用于课堂演示与成果展示（见仓库根目录「CSI室内占据检测成果展示.pptx」）。
