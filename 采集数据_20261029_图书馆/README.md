# 图书馆探索采集数据（2026-10-29 · 图书馆 3 楼）

第二批真实采集，在**图书馆 3 楼**进行（jsonl 元数据 `room:"图书馆3L"`），
用于观察多场景、多人状态下 CSI 信号形态，为正式采集方案探路。
**未进入 Model_v9 训练集**（V9 只用 2026-11-03 当天数据）。

每个场景一对文件：

- **`.jsonl`** —— 原始 CSI 记录（V8 schema：metadata / csi / summary 三种行；
  每条含 64 子载波 IQ、幅度、相位、RSSI、`raw_csi_v8_base64`）。
  录制端有 **20 MB 上限**，到上限即结束一段（summary 行会记录），
  所以多数场景就是一段约 20 MB 的记录。
- **`.png`** —— 采集时的现场照片。

## 各场景说明

| 文件名前缀 | 场景 | 说明 |
|---|---|---|
| 无人 | 空场无人 | 区域内无人，噪声基线 |
| 无人 外面有人走动 | 无人 + 区域外走动 | 区域内无人，外面有人经过，用于考察「区域外干扰」 |
| 两个人学习 | 两人静坐学习 | 区域内两人、基本静止 |
| 一群人学习 | 多人学习 | 区域内多人、偶有小动作 |
| 有人 一个人走动 | 单人走动 | 区域内一人走动 |
| 一个人玩电脑（照片名「有人 玩电脑」） | 单人玩电脑 | 区域内一人在电脑前 |
| 进出门 | 进出门过渡 | 人员进出区域的过程 |

## 标签口径（与全项目一致）

- 「有人」= 人在有效区域内（学习 / 走动 / 玩电脑等）
- 「无人」= 空场、人在区域外走动
- 照片用于说明现场布置，不是与信号同步的视频，不能凭照片推断
  某一时刻的人员状态。
