v0.3 新增功能：保存曲线图片
停止记录后，分别点击“导出数据”和“保存曲线图片”，得到同一实验编号的 JSONL 和 PNG。
“保存曲线图片”会先停止当前记录，再绘制从本次记录第一帧到最后一帧的全部子载波幅度曲线。横轴为设备采集时间（相对首帧秒数），纵轴为 CSI 幅度。图片包含物体、位置、动作、设备、时长和帧数。
不进行平滑，零值保留；缺帧或明显时间间隔处断线。静态图像存在像素分辨率限制，细节分析仍以 JSONL 为准。此图与官网滚动窗口的配色和显示范围可能不同。
只保存 PNG 不算导出数据，请仍点击“导出数据”。刷新前确认两个文件均已下载。

更新安装：先导出旧页面尚未保存的数据。在 chrome://extensions/ 移除旧扩展，再用“加载未打包的扩展程序”选择本文件夹，刷新官网。不要同时启用两个版本。

原始 CSI 记录器 · 官网版 v0.3

本包用于官网 https://espectre.dev/ ，不再运行本地服务器。它是数据采集组件，尚未训练分类模型。

安装（Chrome）：
1. 完整解压文件夹。
2. 地址栏打开 chrome://extensions/ 。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的 CSI_Official_Recorder 文件夹。
5. 刷新官网页面，右下角应出现“原始 CSI 记录器 · 官网版”。
6. 在官网照常连接 ESP32 并启动 CSI visualizer 原始曲线。
7. 等记录器提示已收到真实 CSI，再填写物体、位置、动作、设备 ID 等，点击“开始记录”。
8. 实验结束点击“停止记录”再“导出文件”，到浏览器下载文件夹确认 .jsonl 文件已下载。
9. 换物体/位置/条件时，新建一段。第一次先录 10–20 秒，检查帧数和导出文件。

如果没有面板：确认扩展已启用、访问的是 https://espectre.dev/ 并刷新。若长期显示“等待官网数据解析器”，请提供官网页面和扩展错误信息，可能是官网改了接口。不要关闭浏览器安全检查、修改设备权限或重刷固件来安装本扩展。

机制：
扩展只在 espectre.dev 官网注入面板，复用官网已获授权的数据连接，读取公开的 ESPectreRawCsiParser.append 返回的真实帧。不会打开第二条 CSI 流，不修改设备网络请求、固件设置或访问来源，不捕获演示模式数据。
支持本次检查的官方 CSI V8 格式。官网代码更新可能导致不兼容，不能保证所有后续版本可用。

每个 JSONL 文件包含：
metadata：实验编号、物体、位置、动作、设备 ID、视频名、场地、初始标签和开始时间。
csi：每帧 I/Q、幅度、原始相位、设备时间、浏览器收到时间、RSSI、噪声底、估算 SNR、序号、设备诊断计数、原始 CSI V8 记录的 Base64 字节。
event：人工事件备注及其电脑时间、附近帧的设备时间。
summary：帧数、结束时间和软件保存状态。

幅度由 sqrt(I^2+Q^2) 计算；相位为 atan2(Q,I)，不是经过官网 relative-phase-trails 处理后的相位。原始字节仅包含 CSI V8 记录头和 I/Q 载荷，不含 HTTP 传输前缀。
设备时间不是电脑日期；电脑收到时间受延迟影响。人工事件标记仍需与手机视频核对，不代表精确同步。
计数器相对官网整条数据连接累计，第一条记录可能非零；不补齐丢包。
所有初始标签 label_verified=false，必须经过视频核对才能作为训练真值。

保存限制：
导出前暂存在浏览器内存。刷新、关闭、崩溃可能丢失未导出的内容。
每段上限 20 MB（按序列化文本计算，实际内存会更多）；达到上限自动停止，导出后重新开始一段。
停止后可重复点击导出。按钮触发下载不等于已经确认磁盘写入成功，请检查下载文件。
无数据时显示警告。流重启导致序号回退会停止记录；没有数据的空白时段不代表无运动。
本版不自动上传，未配置云服务/API，也不会产生云端费用。所有原始数据在浏览器内存及用户下载的文件中。

云端训练：
确定平台后，可手动上传 JSONL 和 load_for_training.py，在云端 Python 环境读取。
示例：
from load_for_training import load_session
metadata, frames, events, summary = load_session("CSI_文件名.jsonl")
amplitudes = [frame["amplitude"] for frame in frames]

本脚本只读取数据，不训练模型。训练还需要视频核验的标签、多个独立采集场次、训练/验证/测试划分。通用对话 AI 的调用并不自动等于训练自己的 CSI 模型。云端训练与后续推理的平台、费用、模型和上传权限需另行确定。

验证：已用官方源码解析器和构造数据验证分片解析、I/Q 和幅度、原始字节一致性、事件、结束记录、序号回退和容量上限。未在你们的电脑和 ESP32 上完成实测，未完成浏览器扩展视觉验证。
