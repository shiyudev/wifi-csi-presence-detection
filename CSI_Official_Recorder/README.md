# 官方 CSI 采集工具 v0.3

ESPectre 官方提供的浏览器端采集工具（扩展/脚本形式），
小组第一次采集（[采集数据](../采集数据/)）就是用它完成的。

## 文件说明

| 文件 | 内容 |
|---|---|
| `recorder.js` | 采集主逻辑：连设备、拉 CSI 流、实时保存 |
| `plot.js` | 实时绘图（曲线展示） |
| `core.js` | 核心功能（设备通信等） |
| `manifest.json` | 扩展清单 |
| `load_for_training.py` | 把采集导出的数据转成训练程序能读的格式 |
| `README.txt` | 官方使用说明（安装、采集、导出步骤） |

## 与本地工具链的关系

- 官方工具 = 「看 + 采集」都行，是小组第一次实验的主力
- 本仓库另一套 `scripts/` + Web 控制台 = 同路数据、可训练可检测的完整流水线
- 两者读的是设备上同一条 CSI 流，**不要同时使用**（流独占）
