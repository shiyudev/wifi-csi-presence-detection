# 房间与设备布置

用户提供的五张房间照片，以及11月3日同名训练视频，用于理解室内外空间关系。

- 路由器：此前图一左侧椅子上。
- ESP32：此前图一两台电脑中的右侧电脑旁。
- 房间与外侧走道之间可见大面积玻璃隔断。

屋内有人为1；屋内无人、门外有人走动为0。按用户进一步说明，11月3日无人与门外走动1～5号图中，左蓝线之前为出门过程、右蓝线之后为进门过程，两段都作为屋内有人训练。

本轮按各图蓝线分别确定时间区间，旧数据的统一前15秒裁切规则不套用到今天的文件。门状态、精确距离和无线感应边界未从照片推定。照片没有作为模型输入。
