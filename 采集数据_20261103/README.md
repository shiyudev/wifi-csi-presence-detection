# 正式采集数据（2026-11-03 · 房间 6B514）

第三次采集，也是 **Model_v9 的全量训练集**：4 类场景 × 各 5 段，共 20 份
原始录制，全部进入训练（345 个 2 秒窗口 / 690 秒）。没有混入以前房间的数据。

每段按场景有：

- **`.jsonl`** —— 原始 CSI 记录（V8 schema：metadata / csi / summary 三种行；
  每条含 64 子载波 IQ、幅度、相位、RSSI、`raw_csi_v8_base64`）
- **`.png`** —— 采集时的现场照片
- **`.mp4`** —— 同步视频（仅玩电脑、走动两类有），用于逐窗标签核对

## 各场景说明

| 文件前缀 | 场景 | 段数 | 说明 |
|---|---|---|---|
| 无人（1-5） | 屋内无人 | 5 | 出门 / 空场 / 进门三段过程（详见标签口径） |
| 玩电脑（1-5） | 屋内有人玩电脑 | 5 | 含视频，用于核对「有人」标签 |
| 走动（1-5） | 屋内走动 | 5 | 含视频，用于核对「有人」标签 |
| 门外走动（1-5） | 屋内无人、门外走动 | 5 | 区域外干扰样本，标为「无人」 |

## 标签口径（与 Model_v9 一致）

- 「有人」= 屋内有人（1），「无人」= 屋内无人（0）
- **无人 / 门外走动** 两类的照片上画了蓝线：左蓝线之前是出门过程、
  右蓝线之后是进门过程，这两段按「屋内有人」标注；蓝线之间是屋内无人。
  画线版照片见 [Model_v9/evidence/](../Model_v9/evidence/)。
- 训练窗口固定为每 2 秒一窗，只有整窗落在同一标签区间、且采样质量
  通过才进入训练；边界窗与视频未完整覆盖的窗口排除（逐窗审计见
  [Model_v9/results/window_audit.csv](../Model_v9/results/window_audit.csv)）。
