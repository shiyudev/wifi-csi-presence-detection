# 第一次采集数据（2026-10-21）

每个场景有两类文件，名字一一对应：

- **`.jsonl`** —— 检测预测日志（逐条记录时间、状态、分数、pps、RSSI 等）
- **`.png`** —— 采集时的现场照片

数据在 6B514 房间采集，每段 24~28 秒、约 100 pps、无丢包（seq_gaps = 0）、
RSSI 约 -46 ~ -47 dBm（统计见 [csi_analysis/summary.json](../csi_analysis/summary.json)）。

## 各场景说明

| 文件名前缀 | 场景 | 段数 | 说明 |
|---|---|---|---|
| 玩电脑（1-3） | 有人玩电脑 | 3 | 人在设备旁「连线」位置正常用电脑，属于「区域内有人」样本 |
| 空场无人（1-2） | 空场无人 | 2 | 房间内无人，噪声基线 |
| 走动（1-3） | 走动 | 3 | 人在设备有效区域内走动 |
| 设备旁挥手（1-2） | 挥手 | 2 | 人在设备旁原地挥手 |
| 风扇无人（1-3） | 仅风扇运行 | 3 | 房间无人，只有风扇在转（干扰源样本） |
| 门口走 | 门外走动 | 1 | 人在门外（区域外）走动，不应判为「有人」 |
| 起身出教室 | 离开过程 | 1 | 人从座位上起身、走出教室的过渡过程 |

## 标签口径（与 Model_v2 一致）

- 「有人」= 人在有效区域内（玩电脑、走动、挥手等）
- 「无人」= 空场、仅风扇运行、人在门外
- 照片用于说明现场布置，不是与信号同步的视频，不能凭照片
  推断某一时刻的人员状态；标签以文件名为准（见 Model_v2/labels.json）
